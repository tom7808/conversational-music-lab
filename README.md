# 会話で音楽を学ぶ実験室

ブラウザでリズムを聴き比べ、自分で変え、AIとの会話で理解を深める音楽学習Webアプリの企画です。音楽に興味がある初心者に向けて、「聴く → 変える → 質問する → もう一度聴く」という体験を検討しています。

現在は企画文書の公開段階で、アプリは未実装です。クライアント登録、実装、実動作検証には未着手で、需要や学習効果も今後確かめます。

本プロジェクトでは収益化を行いません。本物のSIWCと利用者本人のChatGPTプランによる推論、複数利用者の分離を実際に学習・検証し、非収益化のWebアプリを公開することを目指します。OpenAIへ必要な利用申請を行う方針は決定済みです。申請対象は、複数の利用者がそれぞれのChatGPTアカウントで使うホスト型Webアプリに決定済みです。ホスト型の適用条件と承認取得は未確認です。

非収益化だけでSIWCの利用条件に適合するとは判断しません。公式DevKitのライセンスとSIWCの利用許可は別に確認します。2026年10月10日 18:33 JSTに公式SIWC Interest formを送信し、画面上で受付を確認しました。これは利用承認ではなく、ホスト型の条件・承認は未確認です。詳細は[送信・受付記録](docs/application-draft.md)に記載しています。

2026年10月10日に[SIWC利用条件の公式資料調査](docs/siwc-research.md)を行い、登録・callback・資格情報保管・DevKitの条件と未解決事項を記録しました。共有バックエンドへの適用と利用承認は未確定です。企画文書の公開を進め、将来は実装する自作コードもOSSとして公開する予定です。

## 必須条件

- 実際のSign in with ChatGPT（SIWC）で認証し、利用者が許可した本人のChatGPTプランによるモデル応答を得ること。
- 利用者ごとの認証情報・ログイン状態・会話・リズムのパターンを分離すること。
- 想定する提供形態の利用条件を確認すること。共有バックエンドでの複数利用者対応やSIWC利用の承認は未確認です。

作業・開発スペースはCodexクラウドに決定しています。初回のSIWC実認証試験は、macOS のローカル環境で、同一 PC 上のブラウザ＋ローカルバックエンドを計画上採用済みです。ローカル環境は事前検証用に限ります。本番の具体的なホスト先と、ホスト型の条件・承認は未決定・未確認です。実装は明確な開始指示を受けてから進めます。
