# 公開準備スナップショットの確認

確認日：2026年10月10日

## 対象と移行方針

README、LICENSE、docsの5文書、計7ファイルを対象とする。確認済みの現行文書だけを、新規リポジトリ `conversational-music-lab` に独立したスナップショットとして置く。旧リポジトリのGit履歴、Gitメタデータ、`.git` は持ち込まない。新規リポジトリは公開判断まで非公開で管理する。

本確認は文書の公開準備であり、リポジトリ公開の実施、SIWCの利用承認、アプリ実装・実認証試験の完了を意味しない。

## 現行文書に施した変更

- 非公開の出典ページへのリンクと固有識別子を除去した。読者はこのリポジトリ内の企画書を参照できる。
- 個人情報の別保管先は一般表現とし、非公開の保管場所へのリンクを掲載しない。
- リポジトリ内の文書は相対リンクとし、移行元リポジトリへ依存しない。
- 旧履歴のメタデータ、旧コミットへの参照、履歴件数、履歴修正手順は本スナップショットに再掲しない。
- 自作部分のMITライセンスと `Copyright (c) 2026 tom7808` は保持した。

## 企画の整合性

- 本プロジェクトの運営方針は非収益化。自作MIT部分について他者の商用利用を認めることとは区別する。
- 実際のSIWCと本人のChatGPTプランによる推論、複数利用者の分離を目標として保持する。クライアント登録、申請送信、実装、実認証・実推論は未実施。
- 開発場所はCodexクラウド。計画上の初回認証試験は、macOSの同一PC上のブラウザとローカルバックエンド。環境選定は実行開始の許可とは区別する。
- 単一runtimeでのアカウント切り替え、独立runtimeでの試験、共有バックエンドのアクセス制御試験を区別する。模擬応答やブラウザ分離だけで実認証・利用者分離の完了としない。
- 共有ホスト型・複数利用者構成の適用条件と承認は未解決。DevKitは未導入であり、採用条件・ライセンス適合性も未確定。
- パスワード、トークン、認可コード、PKCE verifier、秘密を含むcallback URL・ログは文書に記載しない。

## 文書公開前に確認する事項

1. 新規リポジトリが意図した7ファイルだけを含み、旧履歴を引き継いでいないこと。リモートへの保存後に確認する。
2. 新規コミットのauthor・committerに意図した公開用識別情報を使用し、そのメールアドレスが意図しない個人情報を含まないこと。コミット作成時に確認する。
3. 著作権表示のGitHubハンドルと現行文書の公開範囲、公開時期について所有者が判断すること。公開切り替えは別途の明示指示を要する。
4. 公開前に必要な公式情報・外部リンクの現行性を再確認すること。調査日以降の変更は本スナップショットの確認だけでは保証しない。

文書の公開と、SIWCを利用したアプリの提供開始は別の判断である。共有サービスのSIWC承認取得を、この企画文書だけの公開に一律必須とするものではない。

## サービス利用・申請・実装前に残る事項

- 共有バックエンドの登録方式、callback、user/workspace/client/hostの対応、資格情報保管・更新権限、必要な承認を確認する。
- 個人の非収益化案件の申請窓口、会社名・業務用メール等の記入方法、企画段階の申請可否、公開リポジトリ・デモ・完成アプリの要否を確認する。申請者の個人情報は公開文書に記載しない。
- DevKitを採用する場合、Noncommercialの定義と配布条件への適合性を確認する。自作部分のMITはDevKitの独自ライセンスを置き換えず、SIWCサービス利用許可も与えない。
- 実装・実行準備・ログイン・実認証試験は別途の明確な開始指示を受けてから行う。学習効果と複数利用者分離は実動作で検証する。

詳細は[未決事項](open-questions.md)、[SIWC調査記録](siwc-research.md)、[認証試験計画](auth-test-plan.md)を参照する。

## 確認範囲と限界

ローカルの現行7ファイルについて、非公開ページ識別子・移行元へのリンク・具体機種名・代表的な資格情報形式の補助走査と、リポジトリ内相対リンクの確認を行った。該当なしを確認したが、形式外の秘密やあらゆる個人情報の不存在を証明するものではない。

旧リポジトリやそのサーバー側キャッシュの削除・公開化・履歴修正は本移行の対象外である。本スナップショットの清掃を、旧保管先の情報削除が完了したという主張にはしない。リモート保存後のファイル・履歴・コミットメタデータ検証は移行作業側で行う。


## 新正本の履歴・公開用識別情報の確認結果

2026年10月10日、申請準備下書き追加前の新正本を検証した。既存の全7コミットのauthor・committerは、ともに公開用ハンドル `tom7808` と承認済みのGitHub noreplyメールで一致している。メールの実値は本書には記載しない。rootコミットは1つで親を持たず、旧リポジトリの履歴への接続がないことを確認した。旧履歴そのものは参照していない。
